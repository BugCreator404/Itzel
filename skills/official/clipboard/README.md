# clipboard

> Skill oficial de [Itzel](https://github.com/BugCreator404/itzel) 🦎

## ¿Qué hace? / What does it do?

**ES:** Lee y escribe el portapapeles del sistema. Multiplataforma
(Windows / macOS / Linux) vía `pyperclip`.

**EN:** Reads and writes the system clipboard. Cross-platform via `pyperclip`.

## Uso / Usage

```
copia hola mundo                  → escribe "hola mundo" al portapapeles
qué hay en el portapapeles        → muestra el contenido actual
copy meeting notes                → writes to clipboard
what's in the clipboard           → shows current content
```

## Permisos / Permissions

`clipboard` — declarado en `skill.json` y verificado por el loader.
